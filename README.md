Rock Paper Scissors Game

A modern, interactive web-based implementation of the classic Rock, Paper, Scissors game. Built using **HTML**, **CSS**, and **JavaScript**.

 Features:
* Interactive UI: Clean and responsive design.
* Score Tracking: Keeps count of player and computer wins in real-time.
* Game Logic: Randomized computer choices with instant win/lose/draw evaluation.

Technologies Used:
* HTML - For structure
* CSS - For styling and layout
* JavaScript - For game logic and interactivity
